# ZoneGuide

A free WoW addon for the Forever realms, Alliance only for now. It tells the player the best zone to level in, when to move on, and which quests to do there. It does nothing automatically. README.md explains how it decides and where the data comes from.

## Layout
- `ZoneGuide/` is the addon itself:
  - `ZoneGuide.toc`
  - `Core.lua`: zone scoring and the stay or move verdict, with the tuning constants at the top.
  - `UI.lua`: the `/zg` window, including the "Map pins" toggle (bottom left, saved as `ZoneGuideDB.markAll`) and each zone's quest gold next to its level estimate.
  - `Map.lua`: the single pin from clicking a quest, and the "Map pins" markers on every quest giver.
  - `Data_*.lua`: generated by `tools/build_data.py`. Never edit them by hand; change the script and rebuild.
- `tools/`:
  - `build_data.py`: rebuilds the data files.
  - `test_addon.py`: a Lua 5.1 mock of the game API.
  - `zones_alliance.json`: the zones that get scored.
  - `extract_rxp.py`: reads RestedXP's free starting-zone guides.

## Rules
- This folder is the working copy. After each change, also copy the inner `ZoneGuide` folder to `C:\Program Files (x86)\World of Warcraft\_forever_\Interface\AddOns\ZoneGuide`.
- The project is also kept on GitHub at https://github.com/pixelFolly/WoW_Addon. Push each finished change there too.
- Don't decrypt or use RestedXP's paid guide content. The only data sources are:
  - RestedXP's free guides (CC BY-NC-SA 4.0), so the addon stays free and credits RestedXP.
  - QuestieDB and Questie (GPLv3).
- The code is Lua 5.1. The Forever client has the modern APIs (C_Map, C_QuestLog, C_Reputation). The toc's `## Interface` is `16001, 11508`. Bump `## Version` for each release (currently 0.7.0).

## Tyler's preferences
- Quests are sorted by level by default, with a Level/XP toggle. The window must stay resizable.
- Finish a zone before moving on (`FINISH_ZONE = true`), with no ping-ponging between zones.
- Don't say "stay" for a zone with only 1 or 2 quests left (`MIN_OPEN_STAY = 3`).
- The zone estimate only counts quests within 2 levels of you (`MAX_ABOVE = 2`); harder ones count once the zone's own quest XP would get you there.
- No guessed numbers: kill XP is left out of every estimate because drop rates aren't in the data. Only add it back if it can be accurate.
- A star marks a greyed-out quest that is worth unlocking.
- The starting route follows the starting zone you're in, not your race.
- The dungeon section lists every quest of each dungeon that suits your level, grouped by dungeon.
- Each zone shows the gold from turning in the quests its level estimate counts. Quest gold isn't in QuestieDB or Questie, so it comes from the game (`GetQuestLogRewardMoney`, `HaveQuestData`, `C_QuestLog.RequestLoadQuestByID`), cached in `ZoneGuideDB.money` per client build. A "+" means some rewards haven't loaded yet. The mock in `test_addon.py` uses made-up amounts.

## Build and test
These need Python 3 with `lupa` (`pip install lupa`), plus clones of github.com/RestedXP/RXPGuides, github.com/Questie/QuestieDB and github.com/Questie/Questie.
```
python tools/build_data.py <RXPGuides> <QuestieDB> <Questie> ZoneGuide
python tools/test_addon.py ZoneGuide                    # spot checks
python tools/test_addon.py ZoneGuide sim Human WARRIOR  # simulated 12 to 60 run
python tools/test_addon.py ZoneGuide checks             # starting route, map pins, dungeon section, stay rule
python tools/test_addon.py ZoneGuide clicks             # also: chains, classes
```
Expected v0.6 sim results (Human Warrior, Night Elf Druid): 775 to 780 quests, 33 to 37 zone moves, 3 to 6 of them back to the zone before (only after its quests within reach are done), and about 75 grind stops of 0.05 levels each. The sim gives 80% extra XP for kills, which the addon itself doesn't predict.
